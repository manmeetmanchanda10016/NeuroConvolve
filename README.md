# 〰️ NeuroConvolve
### Where Mathematical Convolution Meets Neural Networks

NeuroConvolve is an interactive mathematical convolution simulator that combines **numerical integration** and **deep learning** to explore how two signals interact.

The application calculates mathematical convolution using numerical integration and compares the actual output with predictions generated by a trained PyTorch Multilayer Perceptron (MLP).

---

## ✨ Features

- **Interactive Signal Generator:** Generate and customize Gaussian, Sine, Square and Triangle signals.
- **Adjustable Parameters:** Modify amplitude, frequency, phase, center and width.
- **Mathematical Convolution:** Calculate convolution numerically using the trapezoidal integration method.
- **AI-Based Prediction:** Use a trained PyTorch MLP to predict convolution outputs.
- **Model Performance:** Evaluate predictions using MAE, MSE and RMSE.
- **Interactive Visualization:** Compare input signals, mathematical convolution and AI predictions.
- **Error Analysis:** Visualize prediction errors.
- **CSV Export:** Download numerical results for further analysis.
- **Streamlit Dashboard:** Explore everything through an interactive web interface.

## 🧮 Mathematical Foundation

### 1. What is Convolution?

Convolution is a mathematical operation that combines two functions to produce a third function. It is widely used in signal processing, image processing, mathematics and engineering.

### 2. Mathematical Convolution

The actual convolution is calculated numerically using the convolution integral:

$$
(f*g)(t)=\int_{-\infty}^{\infty}f(\tau)g(t-\tau)\,d\tau
$$

In this project, the integral is approximated numerically using the **trapezoidal integration method** over a finite sampled interval.

### 3. AI-Based Convolution Prediction

A trained neural network learns the relationship between two input signals and their corresponding convolution output.

The model receives two 64-point signals concatenated into a 128-dimensional input vector and predicts a 64-point output.

---

## 🧠 Deep Learning Model

NeuroConvolve uses a **Multilayer Perceptron (MLP)** implemented using PyTorch.

### Model Architecture

| Layer | Configuration |
|---|---|
| Input Layer | 128 neurons |
| Hidden Layer 1 | 256 neurons + ReLU |
| Hidden Layer 2 | 256 neurons + ReLU |
| Output Layer | 64 neurons |

### Model Workflow

1. Generate two input signals.
2. Concatenate both signals into a 128-dimensional vector.
3. Pass the input through the trained MLP.
4. Generate a 64-point predicted convolution output.
5. Compare the prediction with the numerical convolution result.

The trained model is stored in `models/neuroconvolve_mlp.pth`.

---

## 📊 Model Evaluation

The application calculates three evaluation metrics:

**Mean Absolute Error (MAE)**

$$
MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|
$$

**Mean Squared Error (MSE)**

$$
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

**Root Mean Squared Error (RMSE)**

$$
RMSE=\sqrt{MSE}
$$

These metrics measure the difference between the numerical convolution output and the neural network prediction for the currently selected signals.

## ⚠️ Limitations

- Numerical convolution is an approximation over a finite sampled interval.
- The neural network is trained on a synthetic signal dataset.
- Prediction accuracy may vary depending on the selected signal types and parameters.
- The model may not generalize accurately to signal combinations outside its training distribution.
